# PulseChat

Real-time web chat application built with Node.js, Express.js, Socket.IO, JavaScript, HTML, and CSS.

## Features
- User Registration & Login
- Real-Time Messaging
- Contact Management
- Message History
- Responsive UI
- WebSocket Communication

## Tech Stack
- Node.js
- Express.js
- Socket.IO
- MongoDB
- JavaScript
- HTML
- CSS
